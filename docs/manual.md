# 사용자 매뉴얼 (도민용)

**우리 동네 장사 지도**는 "여기서 가게를 하면 어떨까?", "우리 가게 매출이 동네 평균보다 어떤가?" 같은 질문에 쉬운 말과 그래프로 답하는 프로그램입니다. 이 PC 안에서만 돌고, 키를 넣지 않으면 인터넷도 쓰지 않습니다.

## 1. 시작하기
1. 센터 PC 바탕화면의 폴더에서 `install.bat`(처음 한 번), 그다음 `run.bat` 을 더블클릭합니다.
2. 검은 창이 뜨고 잠시 뒤 브라우저에 화면이 열립니다. (검은 창은 닫지 마세요. 끝낼 때 닫습니다.)
3. 화면 위쪽에 "가상 데이터(시연용)입니다"라고 나오면 연습용 숫자로 보는 중입니다. 센터 CSV 를 올리면 실제 분석이 됩니다.

## 2. 질문하기
- 예시 버튼을 누르면 바로 분석합니다. 직접 쓸 때는 **동네 이름 + 업종 + 궁금한 것**을 한 문장으로 쓰세요.
  - "애월읍에 카페를 내면 어때?" (입지 진단)
  - "성산읍에 카페가 너무 많은가요?" (경쟁)
  - "중문동 카페는 몇 시에 제일 잘 돼?" (시간대·요일)
  - "구좌읍 일식집은 비 오는 달에 매출이 줄어?" (계절·날씨)
  - "노형동 한식집 매출이 동네 평균보다 어때?" (내 가게와 비교)
- 동네나 업종을 못 알아들으면 "이렇게 이해했어요" 칸에서 직접 고르고 **이 조건으로 다시 분석**을 누릅니다.
- 치킨집·분식집은 센터 카드 자료의 업종 구분에 따로 없어서 비슷한 업종(예: 간이음식)을 골라야 합니다.

## 3. 센터에서 CSV 받아 오기
1. 질문 아래 **센터에서 받아 올 CSV 체크리스트**를 엽니다. 표 번호·표 이름·받을 조건(기간, 동네, 업종코드)이 나옵니다.
2. 센터 PC 에서 그 조건으로 내려받은 CSV 를 왼쪽 **센터에서 받은 CSV 올리기**에 끌어다 놓습니다. 파일이 여러 개여도 됩니다.
3. 열 이름이 달라도 자동으로 맞춥니다. ✅ 이면 성공, ⚠️ 이면 이유가 적혀 있으니 안내대로 표 종류와 열을 직접 고르세요.
4. 성별·연령대·이용자 구분 열이 있어도 괜찮습니다(프로그램이 합쳐서 씁니다).
5. 사업자번호·기업명이 들어 있는 원본 표는 올릴 수 없습니다(안내 문구가 나옵니다).

## 4. 결과 읽는 법
- **맨 위 파란 상자**: 한 줄 결론입니다. 예: "유리 2개, 불리 2개" — 확인한 신호 중 좋은 것과 걱정되는 것의 개수입니다.
- **쉬운 말 요약**: 문장 끝 `[근거표 3]` 은 아래 3번 표와 그래프에서 확인하라는 뜻입니다.
- **가상 데이터 / 실데이터 표시**: 각 단계 제목 옆 색 딱지입니다. 노란색은 연습용 가상, 초록색은 공개된 실제 자료입니다.
- **비공개**: 근거가 되는 건수가 10 미만인 칸은 개인·가게가 드러날 수 있어 숫자를 가립니다(센터 반출 기준). 매장이 적은 동네에서 자주 보입니다.
- **지수**: 읍면동 평균을 100으로 놓았을 때의 값입니다. 150이면 평균의 1.5배입니다.
- **한계**: 꼭 읽으세요. 카드로 결제한 금액만 잡히고, 과거 자료이며, 미래를 보장하지 않습니다.

## 5. 내 가게와 비교하기
1. 엑셀에서 두 열(연월, 매출)만 만들어 CSV 로 저장합니다. 예: `2026-01, 21500000`
2. 왼쪽 **내 가게 CSV** 에 올리고 "노형동 한식집 매출이 동네 평균보다 어때?"처럼 묻습니다.
3. 내 매출 금액은 이 화면 안에서만 쓰입니다. LLM 으로도, 보고서로도 나가지 않고(보고서에는 비율·흐름만) 분석 후 삭제할 수 있습니다.

## 6. 보고서 저장
결과 아래 **보고서 HTML 내려받기**를 누르면 1~2쪽짜리 보고서가 저장됩니다(그래프는 그림 파일 형태). 센터 밖으로 가져가려면 센터의 반출 신청이 필요합니다. 인쇄하려면 브라우저 인쇄에서 A4 로 하세요.

## 7. 개인 자료 지우기
분석이 끝나면 왼쪽 맨 아래 **올린 자료 모두 삭제**를 누르세요. 올린 CSV 와 이번에 저장한 보고서가 지워집니다. 올린 CSV 는 처음부터 디스크에 쓰지 않고 이 창의 메모리에만 있습니다(창을 닫아도 사라집니다).

## 8. LLM(인공지능) 켜기 — 선택
왼쪽 **분석 방식**에서 OpenAI·Claude·Gemini 를 고르고 키를 입력합니다(키는 저장되지 않습니다). 질문 아래 **LLM 에 보내는 내용 미리보기**에서 실제로 가는 글을 먼저 볼 수 있습니다. 호출 수와 예상 비용은 결과의 **분석 기록**에 나옵니다. 키가 없거나 연결이 안 되면 자동으로 오프라인 방식으로 답합니다.

## 9. 문제가 생기면
| 증상 | 해결 |
|---|---|
| "글자 깨짐" 오류 | 엑셀에서 `CSV UTF-8(쉼표로 분리)` 로 다시 저장 |
| "필수 열을 찾지 못했습니다" | 표 종류를 직접 고르고 빠진 열을 골라 **다시 맞추기** |
| "제주 읍면동으로 알아볼 수 있는 행이 …" | 동 이름 열이 맞는지, 행정동명·법정동명을 확인 |
| 그래프가 비었음 | 해당 동네·업종의 자료가 없거나 모두 '비공개'(10 미만)입니다 |
| 브라우저가 안 열림 | 주소창에 `http://localhost:8501` 입력 |
